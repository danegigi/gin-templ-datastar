Practical Go Standard Library Tutorial

1. Introduction

Go includes a large standard library covering:

- Text manipulation
- Input and output
- Files and directories
- JSON and other data formats
- HTTP clients and servers
- Dates and time
- Error handling
- Concurrency
- Logging
- Testing
- Cryptography
- Database access

A package belongs to the standard library when its import path does not contain an external domain.

For example:

import (
	"fmt"
	"net/http"
	"strings"
)

These are standard-library packages.

An external package usually has an import path such as:

import "github.com/go-chi/chi/v5"

This tutorial focuses on the packages you are most likely to use in everyday Go development.

2. "fmt": Formatting and Printing

The "fmt" package handles formatted input and output.

Printing values

package main

import "fmt"

func main() {
	name := "Ginad"
	age := 40

	fmt.Println("Hello, Go!")
	fmt.Println(name, age)
	fmt.Printf("%s is %d years old\n", name, age)
}

Common functions:

Function - Purpose

fmt.Println - Prints values followed by a newline
fmt.Print - Prints values without automatically adding a newline
fmt.Printf - Prints formatted output
fmt.Sprintf - Creates and returns a formatted string
fmt.Errorf - Creates a formatted error

Common formatting verbs

Verb - Meaning

%s - String

%d - Integer

%f - Floating-point number

%t - Boolean

%v - Default representation

%+v - Detailed struct representation

%T - Value type

%q - Quoted string

%x - Hexadecimal

Example:

package main

import "fmt"

type User struct {
	Name string
	Age  int
}

func main() {
	user := User{
		Name: "Ginad",
		Age:  28,
	}

	fmt.Printf("Default: %v\n", user)
	fmt.Printf("Detailed: %+v\n", user)
	fmt.Printf("Type: %T\n", user)
}

Output:

Default: {Ginad 28}
Detailed: {Name:Ginad Age:28}
Type: main.User

Creating strings

Use "fmt.Sprintf" when you need the result as a string:

message := fmt.Sprintf("User %s has ID %d", "Ginad", 1001)
fmt.Println(message)

Creating formatted errors

func findUser(id int) error {
	return fmt.Errorf("user with ID %d was not found", id)
}

3. "errors": Creating and Inspecting Errors

The "errors" package provides basic error creation and inspection.

Creating an error

package main

import (
	"errors"
	"fmt"
)

func validateAge(age int) error {
	if age < 18 {
		return errors.New("user must be at least 18")
	}

	return nil
}

func main() {
	err := validateAge(15)
	if err != nil {
		fmt.Println(err)
	}
}

Sentinel errors

A sentinel error is a package-level error value used to represent a known condition.

package user

import "errors"

var ErrNotFound = errors.New("user not found")

Callers can check it with "errors.Is":

if errors.Is(err, user.ErrNotFound) {
	fmt.Println("The requested user does not exist")
}

Wrapping errors

Use "%w" with "fmt.Errorf":

func loadConfig() error {
	err := readConfigFile()
	if err != nil {
		return fmt.Errorf("load configuration: %w", err)
	}

	return nil
}

The wrapped error preserves the original error.

if errors.Is(err, os.ErrNotExist) {
	fmt.Println("Configuration file does not exist")
}

Extracting custom error types

package main

import (
	"errors"
	"fmt"
)

type ValidationError struct {
	Field   string
	Message string
}

func (e *ValidationError) Error() string {
	return fmt.Sprintf("%s: %s", e.Field, e.Message)
}

func validateEmail(email string) error {
	if email == "" {
		return &ValidationError{
			Field:   "email",
			Message: "is required",
		}
	}

	return nil
}

func main() {
	err := validateEmail("")

	var validationErr *ValidationError
	if errors.As(err, &validationErr) {
		fmt.Println("Invalid field:", validationErr.Field)
	}
}

Use:

- "errors.Is" to check whether an error matches a particular error value.

- "errors.As" to extract a particular error type.

4. "strings": Working with Strings

The "strings" package provides functions for searching, modifying, splitting, and joining strings.

package main

import (
	"fmt"
	"strings"
)

func main() {
	text := "  Go Standard Library  "

	fmt.Println(strings.TrimSpace(text))
	fmt.Println(strings.ToLower(text))
	fmt.Println(strings.ToUpper(text))
	fmt.Println(strings.Contains(text, "Go"))
}

Frequently used functions

Function - Purpose

"strings.Contains" - Checks whether text contains another string

"strings.HasPrefix" - Checks a prefix

"strings.HasSuffix" - Checks a suffix

"strings.Split" - Splits a string

"strings.Join" - Joins strings

"strings.TrimSpace" - Removes surrounding whitespace

"strings.ReplaceAll" - Replaces matching text

"strings.ToLower" - Converts text to lowercase

"strings.ToUpper" - Converts text to uppercase

"strings.Fields" - Splits text by whitespace

"strings.Builder" - Builds strings efficiently

Splitting and joining

csv := "apple,banana,orange"

fruits := strings.Split(csv, ",")

for _, fruit := range fruits {
	fmt.Println(fruit)
}

result := strings.Join(fruits, "  - ")
fmt.Println(result)

Output:

apple
banana
orange
apple  - banana  - orange

Replacing text

slug := strings.ReplaceAll(
	strings.ToLower("Go Standard Library"),
	" ",
	"-",
)

fmt.Println(slug)

Output:

go-standard-library

Using "strings.Builder"

Repeated string concatenation can create unnecessary allocations. Use "strings.Builder" when constructing larger strings.

package main

import (
	"fmt"
	"strings"
)

func main() {
	var builder strings.Builder

	builder.WriteString("Hello")
	builder.WriteString(", ")
	builder.WriteString("Go!")

	result := builder.String()
	fmt.Println(result)
}

Building HTML:

func buildList(items []string) string {
	var builder strings.Builder

	builder.WriteString("<ul>")

	for _, item := range items {
		builder.WriteString("<li>")
		builder.WriteString(item)
		builder.WriteString("</li>")
	}

	builder.WriteString("</ul>")

	return builder.String()
}

For untrusted content, use "html/template" instead of manually constructing HTML.

5. "strconv": Converting Strings and Numbers

The "strconv" package converts strings to primitive values and primitive values to strings.

String to integer

package main

import (
	"fmt"
	"strconv"
)

func main() {
	value := "42"

	number, err := strconv.Atoi(value)
	if err != nil {
		fmt.Println("Invalid number:", err)
		return
	}

	fmt.Println(number + 8)
}

Integer to string

id := 1001
text := strconv.Itoa(id)

fmt.Println("User ID: " + text)

Parse other number types

price, err := strconv.ParseFloat("19.95", 64)
if err != nil {
	return
}

enabled, err := strconv.ParseBool("true")
if err != nil {
	return
}

count, err := strconv.ParseInt("500", 10, 64)
if err != nil {
	return
}

Format values

priceText := strconv.FormatFloat(19.95, 'f', 2, 64)
enabledText := strconv.FormatBool(true)
countText := strconv.FormatInt(500, 10)

6. "slices" and "maps": Collection Helpers

Modern Go includes standard-library helpers for slices and maps.

slices

package main

import (
	"fmt"
	"slices"
)

func main() {
	numbers := []int{5, 2, 9, 1}

	slices.Sort(numbers)
	fmt.Println(numbers)

	fmt.Println(slices.Contains(numbers, 5))
	fmt.Println(slices.Index(numbers, 9))
}

Useful operations include:

values := []string{"go", "java", "go", "python"}

values = slices.Delete(values, 1, 2)
values = slices.Compact(values)

copyOfValues := slices.Clone(values)

Sorting custom values

package main

import (
	"fmt"
	"slices"
)

type User struct {
	Name string
	Age  int
}

func main() {
	users := []User{
		{Name: "Gigi", Age: 39},
		{Name: "Ginad", Age: 40},
		{Name: "Gane", Age: 18},
	}

	slices.SortFunc(users, func(a, b User) int {
		return a.Age - b.Age
	})

	fmt.Println(users)
}

maps

package main

import (
	"fmt"
	"maps"
)

func main() {
	original := map[string]int{
		"apple":  5,
		"banana": 3,
	}

	cloned := maps.Clone(original)

	fmt.Println(cloned)
}

Comparing maps:

a := map[string]int{"one": 1}
b := map[string]int{"one": 1}

fmt.Println(maps.Equal(a, b))

7. "sort": Sorting Collections

The "sort" package is still commonly found in existing Go projects.

Sorting primitive slices

package main

import (
	"fmt"
	"sort"
)

func main() {
	numbers := []int{5, 2, 8, 1}
	names := []string{"Gigi", "Ginad", "Gane"}

	sort.Ints(numbers)
	sort.Strings(names)

	fmt.Println(numbers)
	fmt.Println(names)
}

For new code, the generic "slices" package is usually more convenient.

Sorting structs

sort.Slice(users, func(i, j int) bool {
	return users[i].Age < users[j].Age
})

Descending:

sort.Slice(users, func(i, j int) bool {
	return users[i].Age > users[j].Age
})

8. "time": Dates, Durations, and Timers

The "time" package handles dates, times, durations, timers, and tickers.

Current time

package main

import (
	"fmt"
	"time"
)

func main() {
	now := time.Now()

	fmt.Println(now)
	fmt.Println(now.Year())
	fmt.Println(now.Month())
	fmt.Println(now.Day())
}

Formatting time

Go uses a reference date rather than tokens such as "YYYY-MM-DD".

The reference is:

Mon Jan 2 15:04:05 MST 2006

Example:

now := time.Now()

fmt.Println(now.Format("2006-01-02"))
fmt.Println(now.Format("2006-01-02 15:04:05"))
fmt.Println(now.Format("January 2, 2006"))

Parsing time

date, err := time.Parse("2006-01-02", "2026-07-15")
if err != nil {
	fmt.Println("Invalid date:", err)
	return
}

fmt.Println(date)

Adding and subtracting time

now := time.Now()

tomorrow := now.Add(24 * time.Hour)
thirtyMinutesLater := now.Add(30 * time.Minute)

fmt.Println(tomorrow)
fmt.Println(thirtyMinutesLater)

Calendar-based operations:

nextMonth := now.AddDate(0, 1, 0)
nextYear := now.AddDate(1, 0, 0)

Calculating duration

start := time.Now()

time.Sleep(500 * time.Millisecond)

elapsed := time.Since(start)
fmt.Println("Elapsed:", elapsed)

Timer

timer := time.NewTimer(2 * time.Second)

fmt.Println("Waiting...")
<-timer.C
fmt.Println("Timer completed")

Ticker

ticker := time.NewTicker(1 * time.Second)
defer ticker.Stop()

for i := 0; i < 3; i++ {
	<-ticker.C
	fmt.Println("Tick:", time.Now())
}

9. "os": Files, Environment Variables, and Processes

The "os" package provides operating-system functionality.

Environment variables

package main

import (
	"fmt"
	"os"
)

func main() {
	port := os.Getenv("PORT")

	if port == "" {
		port = "8080"
	}

	fmt.Println("Port:", port)
}

Use "LookupEnv" when you need to distinguish between an unset variable and an empty variable:

value, exists := os.LookupEnv("DATABASE_URL")
if !exists {
	fmt.Println("DATABASE_URL is not set")
	return
}

fmt.Println(value)

Command-line arguments

package main

import (
	"fmt"
	"os"
)

func main() {
	fmt.Println(os.Args)

	if len(os.Args) > 1 {
		fmt.Println("First argument:", os.Args[1])
	}
}

Command:

go run . hello

Reading a file

content, err := os.ReadFile("config.txt")
if err != nil {
	return err
}

fmt.Println(string(content))

Writing a file

content := []byte("Hello from Go\n")

err := os.WriteFile("output.txt", content, 0644)
if err != nil {
	return err
}

Opening a file

file, err := os.Open("data.txt")
if err != nil {
	return err
}
defer file.Close()

Creating a file

file, err := os.Create("new-file.txt")
if err != nil {
	return err
}
defer file.Close()

_, err = file.WriteString("Hello, Go!")
if err != nil {
	return err
}

Creating directories

err := os.MkdirAll("storage/uploads/images", 0755)
if err != nil {
	return err
}

Checking whether a file exists

_, err := os.Stat("config.json")

if errors.Is(err, os.ErrNotExist) {
	fmt.Println("File does not exist")
} else if err != nil {
	fmt.Println("Unable to inspect file:", err)
} else {
	fmt.Println("File exists")
}

10. "path/filepath": File-System Paths

Use path/filepath for paths on the local operating system.

package main

import (
	"fmt"
	"path/filepath"
)

func main() {
	path := filepath.Join("storage", "uploads", "image.jpg")

	fmt.Println(path)
	fmt.Println(filepath.Base(path))
	fmt.Println(filepath.Dir(path))
	fmt.Println(filepath.Ext(path))
}

Possible output on Linux:

storage/uploads/image.jpg
image.jpg
storage/uploads
.jpg

Walking through a directory

err := filepath.WalkDir(".", func(
	path string,
	entry os.DirEntry,
	err error,
) error {
	if err != nil {
		return err
	}
	if !entry.IsDir() {
		fmt.Println(path)
	}
	return nil
})

if err != nil {
	return err
}

Matching files

files, err := filepath.Glob("*.json")
if err != nil {
	return err
}

for _, file := range files {
	fmt.Println(file)
}

Use "path", not "path/filepath", for slash-separated URL paths.

11. "io": General Input and Output

The io package defines interfaces and utilities used throughout Go.

Two important interfaces are:

type Reader interface {
	Read(p []byte) (n int, err error)
}

type Writer interface {
	Write(p []byte) (n int, err error)
}

Many Go types implement these interfaces:

- Files

- HTTP request bodies

- HTTP response bodies

- Network connections

- Buffers

- Compressed streams

- Strings readers

This lets functions work with many data sources.

Copying data

source, err := os.Open("source.txt")
if err != nil {
	return err
}
defer source.Close()

destination, err := os.Create("destination.txt")
if err != nil {
	return err
}
defer destination.Close()

_, err = io.Copy(destination, source)
if err != nil {
	return err
}

Reading all data

data, err := io.ReadAll(file)
if err != nil {
	return err
}

fmt.Println(string(data))

Avoid "io.ReadAll" for very large or untrusted streams unless you enforce a size limit.

limited := io.LimitReader(file, 10*1024*1024) // appox 10MB

data, err := io.ReadAll(limited)

Writing a string

_, err := io.WriteString(file, "Hello, Go!\n")

Reading from multiple readers

reader := io.MultiReader(
	strings.NewReader("Hello "),
	strings.NewReader("from "),
	strings.NewReader("Go"),
)

data, err := io.ReadAll(reader)

12. "bufio": Buffered Input and Output

Use bufio for efficient buffered reading and writing.

Reading line by line

package main

import (
	"bufio"
	"fmt"
	"os"
)

func main() {
	file, err := os.Open("data.txt")
	if err != nil {
		fmt.Println(err)
		return
	}
	defer file.Close()

	scanner := bufio.NewScanner(file)

	for scanner.Scan() {
		fmt.Println(scanner.Text())
	}

	if err := scanner.Err(); err != nil {
		fmt.Println("Reading file:", err)
	}
}

Reading user input

reader := bufio.NewReader(os.Stdin)

fmt.Print("Enter your name: ")

name, err := reader.ReadString('\n')
if err != nil {
	fmt.Println(err)
	return
}

name = strings.TrimSpace(name)
fmt.Println("Hello,", name)

Buffered writing

file, err := os.Create("output.txt")
if err != nil {
	return err
}
defer file.Close()

writer := bufio.NewWriter(file)
defer writer.Flush()

for i := 1; i <= 1000; i++ {
	fmt.Fprintf(writer, "Line %d\n", i)
}

Remember to call "Flush", usually with "defer".

Scanner size limit

"bufio.Scanner" has a token-size limit. Increase it when processing unusually long lines:

scanner := bufio.NewScanner(file)

buffer := make([]byte, 64*1024)
scanner.Buffer(buffer, 1024*1024)

This sets a maximum token size of 1 MB.

13. "bytes": Working with Byte Slices

The bytes package is similar to "strings", but it works with "[]byte".

package main

import (
	"bytes"
	"fmt"
)

func main() {
	data := []byte("Hello Go")

	fmt.Println(bytes.Contains(data, []byte("Go")))
	fmt.Println(string(bytes.ToUpper(data)))
}

"bytes.Buffer"

A "bytes.Buffer" can be both read from and written to.

var buffer bytes.Buffer

buffer.WriteString("Hello")
buffer.WriteByte(' ')
buffer.WriteString("Go")

fmt.Println(buffer.String())

It is commonly used when:

- Building request bodies

- Creating files in memory

- Capturing output

- Testing readers and writers

- Working with binary data

Example JSON request body:

payload := []byte(`{"name":"Ginad"}`)

request, err := http.NewRequest(
	http.MethodPost,
	"https://example.com/users",
	bytes.NewReader(payload),
)

14. "encoding/json": JSON Encoding and Decoding

The encoding/json package converts between Go values and JSON.

Struct tags

type User struct {
	ID       int    `json:"id"`
	Name     string `json:"name"`
	Email    string `json:"email"`
	Password string `json:"-"` // exclude this field
}

Tags control JSON field names.

Encoding a value

package main

import (
	"encoding/json"
	"fmt"
)

type User struct {
	ID   int    `json:"id"`
	Name string `json:"name"`
}

func main() {
	user := User{
		ID:   1,
		Name: "Ginad",
	}

	data, err := json.Marshal(user) // struct to json
	if err != nil {
		fmt.Println(err)
		return
	}

	fmt.Println(string(data))
}

Output:

{"id":1,"name":"Ginad"}

Pretty JSON

data, err := json.MarshalIndent(user, "", "  ")

Decoding JSON

input := []byte(`{
	"id": 1,
	"name": "Ginad"
}`)

var user User

err := json.Unmarshal(input, &user) // json to struct
if err != nil {
	return err
}

fmt.Println(user.Name)

Pass a pointer to "json.Unmarshal" so it can modify the destination.

Optional fields by defining pointer

type UpdateUserRequest struct {
	Name  *string `json:"name"` //optional
	Email *string `json:"email"`//optional
}

Omitting empty values

type Product struct {
	ID          int      `json:"id"`
	Name        string   `json:"name"`
	Description string   `json:"description,omitempty"` // omit on empty
	Tags        []string `json:"tags,omitempty"` // omit on empty
}

Streaming JSON

Use json.Decoder and json.Encoder when working with readers and writers.

func handleCreateUser(w http.ResponseWriter, r *http.Request) {
	var request CreateUserRequest

	decoder := json.NewDecoder(r.Body)

	if err := decoder.Decode(&request); err != nil {
		http.Error(w, "invalid JSON", http.StatusBadRequest)
		return
	}

	w.Header().Set("Content-Type", "application/json")
	w.WriteHeader(http.StatusCreated)

	json.NewEncoder(w).Encode(request)
}

Rejecting unknown fields

decoder := json.NewDecoder(r.Body)
decoder.DisallowUnknownFields() // strict check

if err := decoder.Decode(&request); err != nil {
	http.Error(w, "invalid request body", http.StatusBadRequest)
	return
}

This is useful for strict API request validation.

15. "net/url": URLs and Query Parameters

The "net/url" package parses and constructs URLs.

Parsing a URL

package main

import (
	"fmt"
	"net/url"
)

func main() {
	rawURL := "https://example.com/products?page=2&category=books"

	parsed, err := url.Parse(rawURL)
	if err != nil {
		fmt.Println(err)
		return
	}

	fmt.Println(parsed.Scheme)
	fmt.Println(parsed.Host)
	fmt.Println(parsed.Path)
	fmt.Println(parsed.Query().Get("page"))
}

Creating query parameters safely

values := url.Values{}

values.Set("search", "Go standard library")
values.Set("page", "1")

query := values.Encode()

fmt.Println(query)

Output:

page=1&search=Go+standard+library

Modifying a URL

parsed, err := url.Parse("https://example.com/products")
if err != nil {
	return err
}

query := parsed.Query()
query.Set("category", "books")
query.Set("page", "2")

parsed.RawQuery = query.Encode()

fmt.Println(parsed.String())

16. "net/http": HTTP Clients

The "net/http" package provides HTTP client and server implementations.

Simple GET request

response, err := http.Get("https://api.example.com/users")
if err != nil {
	return err
}
defer response.Body.Close()

body, err := io.ReadAll(response.Body)
if err != nil {
	return err
}

fmt.Println(string(body))

For production applications, use a configured "http.Client" with a timeout.

client := &http.Client{
	Timeout: 10 * time.Second,
}

Checking status codes

response, err := client.Get("https://api.example.com/users")
if err != nil {
	return err
}
defer response.Body.Close()

if response.StatusCode < 200 || response.StatusCode >= 300 {
	return fmt.Errorf(
		"unexpected HTTP status: %s",
		response.Status,
	)
}

Creating a request

request, err := http.NewRequest(
	http.MethodGet,
	"https://api.example.com/users",
	nil,
)
if err != nil {
	return err
}

request.Header.Set("Accept", "application/json")
request.Header.Set("Authorization", "Bearer token")

response, err := client.Do(request)

Request with context and timeout

ctx, cancel := context.WithTimeout(
	context.Background(),
	5*time.Second,
)
defer cancel()

request, err := http.NewRequestWithContext(
	ctx,
	http.MethodGet,
	"https://api.example.com/users",
	nil,
)
if err != nil {
	return err
}

response, err := client.Do(request)

Sending JSON

type CreateUserRequest struct {
	Name  string `json:"name"`
	Email string `json:"email"`
}

payload := CreateUserRequest{
	Name:  "Ginad",
	Email: "Ginad@example.com",
}

body, err := json.Marshal(payload)
if err != nil {
	return err
}

request, err := http.NewRequest(
	http.MethodPost,
	"https://api.example.com/users",
	bytes.NewReader(body),
)
if err != nil {
	return err
}

request.Header.Set("Content-Type", "application/json")
request.Header.Set("Accept", "application/json")

response, err := client.Do(request)
if err != nil {
	return err
}
defer response.Body.Close()

Reusing an HTTP client

Do not create a new client for every request.

type APIClient struct {
	baseURL string
	client  *http.Client
}

func NewAPIClient(baseURL string) *APIClient {
	return &APIClient{
		baseURL: baseURL,
		client: &http.Client{
			Timeout: 10 * time.Second,
		},
	}
}

17. "net/http": HTTP Servers

Go can build an HTTP server without an external framework.

Basic server

package main

import (
	"fmt"
	"net/http"
)

func main() {
	mux := http.NewServeMux()

	mux.HandleFunc("/", func(w http.ResponseWriter, r *http.Request) {
		fmt.Fprint(w, "Welcome to the homepage!")
	})
	mux.HandleFunc("POST /items", func(w http.ResponseWriter, r *http.Request) {
		fmt.Fprint(w, "Item created successfully.")
	})
	mux.HandleFunc("GET /items/{id}", func(w http.ResponseWriter, r *http.Request) {

	http.ListenAndServe(":8080", mux)
}

18. "context": Cancellation, Deadlines, and Request Values

The context package carries deadlines, cancellation signals, and request-scoped information.

It is especially important for:

- HTTP requests

- Database operations

- Goroutines

- External API calls

- Graceful shutdown

Cancellation

package main

import (
	"context"
	"fmt"
	"time"
)

func worker(ctx context.Context) {
	for {
		select {
		case <-ctx.Done():
			fmt.Println("Worker stopped:", ctx.Err())
			return

		default:
			fmt.Println("Working...")
			time.Sleep(500 * time.Millisecond)
		}
	}
}

func main() {
	ctx, cancel := context.WithCancel(context.Background())

	go worker(ctx)

	time.Sleep(2 * time.Second)
	cancel()

	time.Sleep(500 * time.Millisecond)
}

Timeout

ctx, cancel := context.WithTimeout(
	context.Background(),
	3*time.Second,
)
defer cancel()

result, err := performOperation(ctx)


Respecting cancellation

func performOperation(ctx context.Context) error {
	select {
	case <-time.After(5 * time.Second):
		return nil

	case <-ctx.Done():
		return ctx.Err()
	}
}

Context rules

1. Pass "context.Context" as the first parameter.

2. Do not store contexts inside long-lived structs.

3. Do not pass "nil"; use "context.Background()" or "context.TODO()".

4. Use context values only for request-scoped metadata.

5. Always call the returned cancellation function.

Good:

func FindUser(ctx context.Context, id int) (User, error)

Avoid:

type UserService struct {
	ctx context.Context
}

19. "sync": Synchronizing Goroutines

The sync package provides synchronization primitives.

sync.WaitGroup - A wait group waits for goroutines to finish.

package main

import (
	"fmt"
	"sync"
)

func main() {
	var wg sync.WaitGroup

	for i := 1; i <= 3; i++ {
		id := i

		wg.Go(func() { // wrapper of Add and Done()
			fmt.Println("Worker", id)
		})
	}

	wg.Wait()
}

For older Go versions, the traditional pattern is:

var wg sync.WaitGroup

for i := 1; i <= 3; i++ {
	id := i

	wg.Add(1)

	go func() {
		defer wg.Done()
		fmt.Println("Worker", id)
	}()
}

wg.Wait()

sync.Mutex - A mutex protects shared state.

package main

import (
	"fmt"
	"sync"
)

type Counter struct {
	mu    sync.Mutex
	value int
}

func (c *Counter) Increment() {
	c.mu.Lock()
	defer c.mu.Unlock()

	c.value++
}

func (c *Counter) Value() int {
	c.mu.Lock()
	defer c.mu.Unlock()

	return c.value
}

func main() {
	var wg sync.WaitGroup
	counter := &Counter{}

	for i := 0; i < 1000; i++ {
		wg.Go(counter.Increment)
	}

	wg.Wait()

	fmt.Println(counter.Value())
}

sync.RWMutex - when reads are frequent and writes are less frequent.

type Cache struct {
	mu    sync.RWMutex
	items map[string]string
}

func (c *Cache) Get(key string) (string, bool) {
	c.mu.RLock()
	defer c.mu.RUnlock()

	value, exists := c.items[key]
	return value, exists
}

func (c *Cache) Set(key, value string) {
	c.mu.Lock()
	defer c.mu.Unlock()

	c.items[key] = value
}

sync.Once - Runs a function exactly once.

var (
	config     Config
	configOnce sync.Once
)

func GetConfig() Config {
	configOnce.Do(func() {
		config = loadConfig()
	})

	return config
}

sync.Map - Do not automatically use it instead of a regular map protected by a mutex.

var cache sync.Map

cache.Store("user:1", "Ginad")

value, exists := cache.Load("user:1")
if exists {
	fmt.Println(value)
}

21. Channels and "select"

Channels are part of the Go language, but their behavior is closely connected to the standard library’s concurrency tools.

Sending and receiving

package main
import "fmt"
func main() {
	messages := make(chan string)
	go func() {
		messages <- "Hello from goroutine"
	}()
	message := <-messages
	fmt.Println(message)
}

Buffered channel

messages := make(chan string, 2)
messages <- "first"
messages <- "second"
fmt.Println(<-messages)
fmt.Println(<-messages)

Closing a channel

The sender normally closes a channel.

jobs := make(chan int)
go func() {

defer close(jobs)

for i := 1; i <= 5; i++ {
		jobs <- i
	}
}()
for job := range jobs {
	fmt.Println(job)
}

"select"

select {

case message := <-messages:
	fmt.Println(message)
case <-time.After(2 * time.Second):
	fmt.Println("Timed out")
}

Worker pool

func worker(

id int,

jobs <-chan int,
	results chan<- int,
) {
	for job := range jobs {
		fmt.Printf("worker %d processing job %d\n", id, job)
		results <- job * 2
	}
}
func main() {
	const workerCount = 3
	const jobCount = 5
	jobs := make(chan int, jobCount)
	results := make(chan int, jobCount)
	for id := 1; id <= workerCount; id++ {
		go worker(id, jobs, results)
	}
	for job := 1; job <= jobCount; job++ {
		jobs <- job
	}

close(jobs)

for i := 0; i < jobCount; i++ {
		fmt.Println("Result:", <-results)
	}
}

Querying one row

type User struct {

ID int64

Name string

Email string

}
func findUser(

ctx context.Context,

db *sql.DB,

id int64,

) (User, error) {

const query = `
		SELECT id, name, email
		FROM users
		WHERE id = $1

`

var user User
	err := db.QueryRowContext(ctx, query, id).Scan(
		&user.ID,
		&user.Name,
		&user.Email,
	)

if err != nil {

if errors.Is(err, sql.ErrNoRows) {
			return User{}, ErrUserNotFound
		}
		return User{}, fmt.Errorf("query user: %w", err)
	}
	return user, nil
}

rows, err := db.QueryContext(

ctx,

`SELECT id, name, email FROM users`,
)

return nil, err
}

defer rows.Close()

var users []User

for rows.Next() {

var user User
	if err := rows.Scan(
		&user.ID,
		&user.Name,
		&user.Email,
	); err != nil {
		return nil, err
	}

users = append(users, user)

}

}

affected, err := result.RowsAffected()

return err

ctx,

			a:    0,
			b:    0,
			want: 0,
		},
	}
	for _, test := range tests {
		t.Run(test.name, func(t *testing.T) {
			got := Add(test.a, test.b)

		if err != nil {
			return
		}

		parsedAgain, err := strconv.Atoi(output)
		if err != nil {
			t.Fatalf("unable to parse output: %v", err)
		}
		if parsedAgain != number {
			t.Fatalf(
				"round trip failed: %d != %d",
				parsedAgain,
				number,
			)
		}
	})
}

Run:

go test -fuzz=FuzzParseNumber

37. "os/signal": Graceful Shutdown

Servers should stop accepting traffic and allow active requests to finish.

package main
import (

"context"

"errors"

"log"

"net/http"

"os"

"os/signal"

"syscall"

"time"

)
func main() {
	mux := http.NewServeMux()

mux.HandleFunc("GET /", func(

w http.ResponseWriter,
		r *http.Request,
	) {
		w.Write([]byte("Hello"))
	})
	server := &http.Server{
		Addr:              ":8080",
		Handler:           mux,
		ReadHeaderTimeout: 5 * time.Second,
	}
	serverErrors := make(chan error, 1)
	go func() {
		log.Printf("server listening on %s", server.Addr)
		serverErrors <- server.ListenAndServe()
	}()
	shutdownContext, stop := signal.NotifyContext(
		context.Background(),
		os.Interrupt,
		syscall.SIGTERM,
	)

defer stop()

select {

case err := <-serverErrors:
		if err != nil &&
			!errors.Is(err, http.ErrServerClosed) {
			log.Fatal(err)
		}
	case <-shutdownContext.Done():
		log.Println("shutdown signal received")
	}
	ctx, cancel := context.WithTimeout(
		context.Background(),
		10*time.Second,
	)

defer cancel()

if err := server.Shutdown(ctx); err != nil {
		log.Printf("graceful shutdown failed: %v", err)
		if closeErr := server.Close(); closeErr != nil {
			log.Printf("forced shutdown failed: %v", closeErr)
		}
	}
	log.Println("server stopped")
}

func inspect(value any) {
	valueType := reflect.TypeOf(value)
	for i := 0; i < valueType.NumField(); i++ {
		field := valueType.Field(i)
		fmt.Println(
			field.Name,
			field.Type,

- Object mapping

- Framework internals

41. Complete Example: Small JSON API

This example combines several commonly used standard-library packages.

package main
import (

"context"

"encoding/json"

"errors"

"log/slog"

"net/http"

"os"

"os/signal"

"strconv"

"sync"

"syscall"

"time"

)
type User struct {

ID int64 `json:"id"`

Name string `json:"name"`

}
type CreateUserRequest struct {

Name string `json:"name"`

}
type UserStore struct {

mu sync.RWMutex

nextID int64

users map[int64]User

}
func NewUserStore() *UserStore {
	return &UserStore{
		nextID: 1,
		users:  make(map[int64]User),
	}
}
func (s *UserStore) Create(name string) User {

s.mu.Lock()

defer s.mu.Unlock()

user := User{
		ID:   s.nextID,
		Name: name,
	}

s.users[user.ID] = user

s.nextID++

return user
}
func (s *UserStore) Find(id int64) (User, bool) {

s.mu.RLock()

defer s.mu.RUnlock()

user, exists := s.users[id]
	return user, exists
}
type Application struct {
	logger *slog.Logger

store *UserStore

}
func (app *Application) routes() http.Handler {
	mux := http.NewServeMux()

mux.HandleFunc("GET /health", app.health)

mux.HandleFunc("POST /users", app.createUser)

mux.HandleFunc("GET /users/{id}", app.getUser)

return app.loggingMiddleware(mux)
}
func (app *Application) health(
	w http.ResponseWriter,
	r *http.Request,
) {
	writeJSON(w, http.StatusOK, map[string]string{
		"status": "ok",
	})
}
func (app *Application) createUser(
	w http.ResponseWriter,
	r *http.Request,
) {
	var request CreateUserRequest
	decoder := json.NewDecoder(
		http.MaxBytesReader(w, r.Body, 1<<20),
	)

decoder.DisallowUnknownFields()

if err := decoder.Decode(&request); err != nil {
		writeJSON(w, http.StatusBadRequest, map[string]string{
			"error": "invalid request body",
		})
		return
	}

if request.Name == "" {

writeJSON(w, http.StatusBadRequest, map[string]string{
			"error": "name is required",
		})
		return
	}
	user := app.store.Create(request.Name)
	writeJSON(w, http.StatusCreated, user)
}
func (app *Application) getUser(
	w http.ResponseWriter,
	r *http.Request,
) {
	id, err := strconv.ParseInt(
		r.PathValue("id"),
		10,
		64,
	)

if err != nil {

writeJSON(w, http.StatusBadRequest, map[string]string{
			"error": "invalid user ID",
		})
		return
	}
	user, exists := app.store.Find(id)

if !exists {

writeJSON(w, http.StatusNotFound, map[string]string{
			"error": "user not found",
		})
		return
	}
	writeJSON(w, http.StatusOK, user)
}
func (app *Application) loggingMiddleware(
	next http.Handler,
) http.Handler {
	return http.HandlerFunc(func(
		w http.ResponseWriter,
		r *http.Request,
	) {
		start := time.Now()
		next.ServeHTTP(w, r)
		app.logger.Info(
			"request completed",
			"method", r.Method,
			"path", r.URL.Path,
			"duration", time.Since(start),
		)
	})
}
func writeJSON(
	w http.ResponseWriter,

status int,

value any,

) {

w.Header().Set("Content-Type", "application/json")

w.WriteHeader(status)

if err := json.NewEncoder(w).Encode(value); err != nil {
		slog.Error("encode JSON response", "error", err)
	}
}
func main() {
	logger := slog.New(
		slog.NewJSONHandler(os.Stdout, nil),
	)
	app := &Application{
		logger: logger,
		store:  NewUserStore(),
	}
	server := &http.Server{
		Addr:              ":8080",
		Handler:           app.routes(),
		ReadHeaderTimeout: 5 * time.Second,
		ReadTimeout:       15 * time.Second,
		WriteTimeout:      15 * time.Second,
		IdleTimeout:       60 * time.Second,
	}
	serverErrors := make(chan error, 1)
	go func() {
		logger.Info(
			"server started",
			"address", server.Addr,
		)
		serverErrors <- server.ListenAndServe()
	}()
	shutdownContext, stop := signal.NotifyContext(
		context.Background(),
		os.Interrupt,
		syscall.SIGTERM,
	)

defer stop()

select {

case err := <-serverErrors:
		if err != nil &&
			!errors.Is(err, http.ErrServerClosed) {
			logger.Error(
				"server failed",
				"error", err,
			)
			os.Exit(1)
		}
	case <-shutdownContext.Done():
		logger.Info("shutdown signal received")
	}
	ctx, cancel := context.WithTimeout(
		context.Background(),
		10*time.Second,
	)

defer cancel()

if err := server.Shutdown(ctx); err != nil {
		logger.Error(
			"graceful shutdown failed",
			"error", err,
		)
	}

logger.Info("server stopped")

}

Run:

go run .

Create a user:

curl -X POST http://localhost:8080/users \
  -H "Content-Type: application/json" \
  -d '{"name":"Ginad"}'

Retrieve the user:

curl http://localhost:8080/users/1

Check health:

curl http://localhost:8080/health

43. Standard-Library Best Practices

Close resources

file, err := os.Open(path)

if err != nil {

return err
}

defer file.Close()

The same applies to:

- HTTP response bodies

- Database rows

- ZIP readers

- Gzip readers

- Files

Wrap errors with context

Good:

return fmt.Errorf("read configuration file: %w", err)

Less useful:

return err

Set network timeouts

client := &http.Client{

Timeout: 10 * time.Second,

}

Also configure server timeouts.

Use context for cancellation

func LoadUser(

ctx context.Context,

id int64,

) (User, error)

Limit untrusted input

reader := http.MaxBytesReader(

w,

r.Body,

1<<20,

)

Prefer streaming for large data

Prefer:

io.Copy(destination, source)

Over reading an entire large file into memory.

Protect shared state

Use:

- "sync.Mutex"

- "sync.RWMutex"

- Channels

- Atomic values

Do not concurrently modify a regular map without synchronization.

Use secure randomness for secrets

Use:

crypto/rand

Not:

math/rand/v2

Use structured logs

logger.Error(

"failed to save user",

"user_id", id,

"error", err,

)

Test behavior

Focus tests on observable behavior rather than internal implementation details.
